# Reflo

Reflo 是独立的桌面论文研究应用，首发 macOS，并保留后续 Windows 支持能力。

## 当前状态

已实现桌面启动、SQLite 初始化、单个 PDF 导入、SHA-256 去重、真实文献列表、标题搜索，以及标题、作者、年份、DOI、来源链接的手动编辑。文献列表采用可展开的论文文件夹：每篇 Paper 下统一展示 PDF 原文、Markdown、论文结构和译文；已实现的文件可直接打开，尚未接入的产物保留明确入口。PDF 复制到应用数据目录，记录持久化保存；源文件保持不变。导入标题默认取文件名，自动识别尚未接入。

元数据需点击“保存修改”后入库；未保存时阻止切换文献，可使用“撤销修改”恢复。作者每行一位，保留署名顺序。后端校验必填标题、年份和 HTTP(S) 链接，通过记录版本检查阻止过期修改覆盖新数据。启动时会将已有数据库升级到版本 3，保留原有记录。

已接入 PDF.js 本地阅读：导入成功后自动打开，或选中文献后点击“阅读 PDF”。支持按钮和鼠标滚轮翻页、输入页码跳转、25%–300% 缩放、⌘/Ctrl + 滚轮缩放、单页/双页浏览、纵向连续滚动、全部页面缩略图、文字层选择，以及页码和缩放比例持久化。双页模式每次前后移动两页，最后不足两页时显示单页。连续模式按原始页面尺寸纵向排列，并按滚动位置更新页码。“全部页面”使用懒加载缩略图，点击任意一页进入对应单页。

选中 PDF 文字后可执行高亮、批注、翻译或复制。高亮与批注按文献和页码保存到 SQLite，缩放或重新打开后仍能恢复，并可从“批注”侧栏跳回原页或删除。翻译会自动在英文和中文之间选择方向，通过独立服务适配层调用 MyMemory；触发翻译时，所选文字会发送至该服务，且其公开接口单次最多处理 500 字节。

扫描件可显示，但无文字层时不能直接选中文字。文件读取仅授权已登记且位于本地文献库中的文件；字体、字符映射和 worker 随应用提供，无需远程解析服务。

已接入 MinerU v4 云端解析，可将文献库中的 PDF 转换为 Markdown，并保存 `full.md` 与提取图片。转换设置支持 VLM/Pipeline、文档语言、OCR、公式和表格识别；API Token 长期保存在 macOS 钥匙串中，明文不会写入 SQLite。转换后的文件位于对应文献目录的 `markdown/` 子目录，可在与 PDF 阅读器一致的全屏工作区中使用排版阅读或 Markdown 源码模式查看和复制。重新转换采用临时目录与上一版备份，成功后才替换已有结果。

导入阶段仅检查标准文件头，损坏文件由阅读器显示加载错误；加密 PDF 暂需先解密。正常错误会清理本次导入产物；进程异常退出后的孤立文件自动恢复尚未实现。

## 开发与验证

需要 Node.js、Rust 和 macOS 开发工具。在项目根目录运行：

```bash
npm ci
npm run tauri dev
```

检查前端构建和后端测试：

```bash
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

手动验收：导入 PDF 后自动进入阅读器；翻页、缩放后等待位置保存完成，返回文献库并重新打开，检查页码和缩放恢复；重启后再次检查。再次导入相同内容时复用原记录；修改元数据并保存后，按新标题搜索。文件选择、入库与本地 PDF 读取需在桌面窗口中操作，单独启动浏览器前端不支持这些原生能力。

`predev` 和 `prebuild` 自动复制 PDF.js 配套资源到 `public/pdfjs/`；该目录为生成内容，不提交 Git。构建本地测试应用可运行 `npm run tauri build -- --debug --bundles app`，输出位于 `src-tauri/target/debug/bundle/macos/Reflo.app`。

## 计划功能

- PDF 文献管理、分类与元数据识别。
- PDF 阅读、高亮与批注。
- 翻译、Markdown 转换与原文定位。
- 单篇论文结构树、跨论文关系与对比阅读。

## 技术方向

- 桌面与本地服务：Tauri 2 + Rust。
- 界面：React + TypeScript + Vite。
- 本地存储与检索：SQLite + FTS5。
- PDF 阅读：PDF.js。
- PDF 解析：API 优先，暂定 MinerU。
- 论文结构与关系展示：React Flow。

## 代码结构

```text
src/
  app/                    应用入口、路由与工作区组装
  features/               文献库、阅读、解析、翻译与研究功能
  shared/                 UI、IPC、接口类型与通用工具
src-tauri/
  src/
    commands/             IPC 命令入口
    application/          业务用例编排
    domain/               领域模型与规则
    infrastructure/       数据库、文件、任务及外部服务适配
  migrations/             数据库迁移
  capabilities/           桌面权限配置
tests/                    测试样本与集成测试
public/                   静态资源
```

界面通过 Tauri IPC 调用 Rust 应用服务。Rust 管理持久化与后台任务，外部解析服务通过适配器接入。本地阅读与批注不依赖远程解析完成。
